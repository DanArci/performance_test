# Student Management System with Data Persistence
Simple app to manage students. Add, consult, remove, search, update and save from CSV.

## How to use it
```bash
python main.py
```

Pick an option from the menu and follow the instructions.

## What it does
- Add students (name, ID, age, course, status)
- View all students
- Search for a student
- Update student info
- Delete students from the list

## Files
- `main.py` - Main menu
- `services.py` - Functions for products
- `files.py` - CSV stuff
- `db.csv` - Data file
